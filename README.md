# Product Landing Page – Assignment

This repository contains a **simple product landing page** created as part of a frontend assignment.

## 🔍 Project Overview

This project was forked from [DevTestGuru/testing](https://github.com/DevTestGuru/testing) as a test assignment. The objective was to build a basic static web page for a fictional product using either **HTML/CSS** or **React**, focusing on structure and responsiveness.

## 📄 Task Description

**Goal:** Create a simple product landing page within 30 minutes.

### Requirements:
- ✅ Header with the product name  
- ✅ Product image  
- ✅ Brief product description  
- ✅ Three product features  
- ✅ Footer with contact information  
- ✅ Responsive design (works on mobile and desktop)

## 💻 Technologies Used

- React
- Typescript 
- Vite
